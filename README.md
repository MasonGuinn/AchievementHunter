# Achievement Hunter 🏆

A high-performance, cross-platform desktop tracker for Steam achievements, built natively with C# and Avalonia UI. 

Designed to bypass the bloat of web-based trackers, this tool interfaces directly with the Steam Web API to provide a crisp, modern, and highly responsive achievement hunting experience.

## Features
* **Direct Steam API Integration:** Securely fetches live profile, game library, and achievement data.
* **Cross-Platform UI:** Built on the Avalonia framework for a native, hardware-accelerated experience on Windows, macOS, and Linux (SteamOS).
* **Smart Sorting:** Advanced filtering to manage completion states and hunt down missing achievements efficiently.

## Tech Stack
* **Frontend:** C#, Avalonia UI, XAML
* **Backend:** .NET (HttpClient, asynchronous JSON parsing)
* **Architecture:** MVVM (Model-View-ViewModel)
* **Security:** .NET User Secrets Manager (Zero hardcoded credentials)
